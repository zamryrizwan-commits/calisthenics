# Home Calisthenics Coach

An 8-week, no-equipment calisthenics plan as an installable web app: daily workouts, a morning mobility routine, animated form guides, timers, XP, streaks and badges.

**Install on iPhone:** open the site in Safari, tap Share, then Add to Home Screen.

Progress is stored on the device. Use Progress › Settings › Copy backup code to keep a copy.

## Files
- `index.html` – the app (built by `build.py` from `app-body.html`)
- `manifest.webmanifest`, `sw.js`, `icons/` – install and offline support
